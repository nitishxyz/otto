---
description: Initialize Argent MCP, skills, and workspace configuration in this project.
---

Run `/argent init` (or the **Initialize Argent** plugin command) from the project root.

After setup:

- Enable the **argent** MCP server in Otto if it is not already running.
- Ask the assistant what Argent can do, or use the bundled **argent-device-interact** skill for simulator interaction workflows.

Official docs: https://argent.swmansion.com
