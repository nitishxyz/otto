Search repository content or filenames. `mode: "content"` (default) uses regex and returns `file`, `line`, and matching text. `mode: "files"` treats `query` as a glob pattern and returns matching paths. Both respect `.gitignore` and support path scoping and bounded results.

Use this instead of shell `grep`/`rg`/`find`. In content mode, narrow with `path` and `glob`; in files mode, use `ignore` for extra exclusions. Keep `maxResults` small for broad searches.
